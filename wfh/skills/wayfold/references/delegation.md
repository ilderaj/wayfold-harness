# Bounded delegation

Use helpers only when permitted by the user and Host. Give each a concrete scope, owned paths, evidence expected, and integration boundary. Preserve the same task authority; helpers do not acquire permission to publish, send messages, or change unrelated state.

The integrator checks the actual diff/output and meaningful tests, resolves conflicts, and records acceptance. A worker's statement, model label, successful tool exit, or install receipt alone is not independent completion evidence. For delegated primary execution require the bound task's progress plus Host completion and independently checked deliverable evidence. Missing evidence remains pending. Do not build a new scheduler or model router to enforce this reference.
