# WayFold Harness

Honor the user's goal, existing authorization, project constraints, and Host permissions. Choose the smallest effective solution. Continue authorized independent work; ask only for a material missing decision or a real access boundary.

For substantial or resumed tracked work, use the sibling [planning-with-files](../planning-with-files/SKILL.md) skill. Preserve the original Task ID and bound three-file authority. Do not create a second intake, infer authority from a title, or restart an existing task after compaction. Quick answers and bounded edits do not require planning files.

For coding, consult [engineering](references/engineering.md) when its checks matter. For documents, explanations, or UI artifacts, consult [artifact quality](references/artifacts.md). For requested simplification audits use [simplification](references/simplification.md). For delegated work read [delegation](references/delegation.md). Load only the relevant reference.

Host discovers and selects independently installed methods. Respect a user's named skill, its source namespace, invocation policy, and available tools. Matt and other authors are equally eligible. Do not install automatically, implement a second router, merge same-named providers, or load retired WFH copies to fill a gap. Report a missing specialist only when it prevents the work.

When the task is bound to Linear, use the sibling [linear-work-control](../linear-work-control/SKILL.md) skill. Otherwise do not require Linear enrollment.

Record verified results, uncertainty, and the next action. Static tests, installation, deployment, and actual user outcomes are different evidence. Never mark complete while a required gate is unverified. Plugin-owned hooks restore and check turn wrap-up only for exact-bound tracked/planned tasks after native trust. Direct work stays unbound. There is no global policy installer, scheduler, or background fallback. Disabling it does not disable independent user skills or erase task data. Previously loaded instructions can remain in an existing conversation; test a switch in a fresh context.
